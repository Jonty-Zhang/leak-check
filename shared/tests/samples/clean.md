# 基于改进 A* 算法的校园导航路径规划

## 1 引言

校园导航需要在复杂路网中快速给出可行路径。本文提出一种改进版 A* 算法，在启发函数中加入路段拥挤度。

### 1.1 研究现状

文献[1]提出了基于栅格地图的规划方法，文献[2]在此基础上引入了动态权重。此处需要补充说明的是，二者都没有考虑人流。

### 1.2 本文工作

本文用待定系数法拟合拥挤度曲线，限于篇幅，此处省略推导过程，详见文献[3]。后续工作需要补充更多时段的数据。
